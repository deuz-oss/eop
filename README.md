# Enterprise Operations Platform (EOP)

Enterprise Operations Platform is a SaaS platform designed to manage distributed field operations such as sales representatives, SPG/SPB, merchandisers, supervisors, and area managers.

Current Status:
Phase 0 — Vision

Architecture:
Modular Monolith (initial)
